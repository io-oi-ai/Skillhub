# Awesome DESIGN.md

将任意网站的 `DESIGN.md` 复制到你的项目根目录，告诉 AI Agent "按照这个设计风格构建页面"，即可获得像素级还原的 UI。

## 什么是 DESIGN.md？

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) 是 Google Stitch 提出的新概念——一个 AI Agent 可读的纯文本设计系统文档。

这只是一个 Markdown 文件，无需 Figma 导出、无需 JSON Schema、无需任何特殊工具。放入项目根目录，任何 AI 编程 Agent 或 Google Stitch 就能立刻理解你的 UI 应该如何呈现。

| 文件 | 读取者 | 定义内容 |
|------|--------|----------|
| `AGENTS.md` | 编程 Agent | 如何构建项目 |
| `DESIGN.md` | 设计 Agent | 项目的视觉风格与感受 |

## 如何使用

1. 从下方集合中选一个你喜欢的网站风格
2. 将其 `DESIGN.md` 复制到项目根目录
3. 告诉 AI Agent：

```
请按照 DESIGN.md 中的设计系统，为我构建一个登录页面。
```

## 每个 DESIGN.md 包含的内容

遵循 [Stitch DESIGN.md 格式](https://stitch.withgoogle.com/docs/design-md/format/)，包含以下章节：

| # | 章节 | 内容 |
|---|------|------|
| 1 | 视觉主题与氛围 | 情绪、密度、设计哲学 |
| 2 | 色彩系统 | 语义颜色名称 + 十六进制值 + 功能角色 |
| 3 | 字体规则 | 字体族、完整层级表 |
| 4 | 组件样式 | 按钮、卡片、输入框、导航及各状态 |
| 5 | 布局原则 | 间距比例、网格、留白哲学 |
| 6 | 层次与阴影 | 阴影系统、表面层级 |
| 7 | 该做与不该做 | 设计护栏与反模式 |
| 8 | 响应式行为 | 断点、触控目标、折叠策略 |
| 9 | Agent 提示指南 | 快速颜色参考、即用提示词 |

每个站点包含三个文件：

| 文件 | 用途 |
|------|------|
| `DESIGN.md` | 设计系统（供 Agent 读取） |
| `preview.html` | 颜色样板、字体比例、按钮、卡片的视觉目录 |
| `preview-dark.html` | 深色表面的同款目录 |

### 直接使用 Claude 风格

```bash

curl -o DESIGN.md https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/design-md/claude/DESIGN.md

```
请参考项目根目录中的 DESIGN.md，为我创建一个产品主页。

# English Version

# Awesome DESIGN.md

Copy a DESIGN.md into your project, tell your AI agent "build me a page that looks like this" and get pixel-perfect UI that actually matches.

## What is DESIGN.md?

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) is a new concept introduced by Google Stitch. A plain-text design system document that AI agents read to generate consistent UI.

It's just a markdown file. No Figma exports, no JSON schemas, no special tooling. Drop it into your project root and any AI coding agent or Google Stitch instantly understands how your UI should look.

## How to Use

1. Pick a site from the collection below
2. Copy its `DESIGN.md` to your project root
3. Tell your AI agent:

```
Please build me a login page following the design system in DESIGN.md.
```

## What's Inside Each DESIGN.md

Every file follows the [Stitch DESIGN.md format](https://stitch.withgoogle.com/docs/design-md/format/) with 9 sections:

1. Visual Theme & Atmosphere
2. Color Palette & Roles
3. Typography Rules
4. Component Stylings
5. Layout Principles
6. Depth & Elevation
7. Do's and Don'ts
8. Responsive Behavior
9. Agent Prompt Guide

Each site includes `DESIGN.md`, `preview.html`, and `preview-dark.html`.
