## 正式版

**标题：** 养了龙虾之后，去哪找好用的 Skill？

**正文：**

最近「养龙虾」火了，身边很多人都装上了 OpenClaw。

但装完之后大家都在问同一个问题：
Skill 去哪找？怎么知道哪个好用？

ClawHub 上有一万多个 Skill，但说实话质量参差不齐。
之前还出过供应链投毒事件，随便装来路不明的 Skill 真的有风险。

——

分享一个我一直在用的网站：SkillHubs（skillhubs.cc）

它做的事情很简单 —— 把真正好用的 Skill 筛出来。

每个 Skill 都是人工精选的，有完整的预览、版本记录、作者信息。
不用担心质量问题，也不用在几千个 Skill 里大海捞针。

——

和你直接在 ClawHub 上找有什么区别？

ClawHub：13000+ 个技能，但 90% 使用率极低或功能重复
SkillHubs：40+ 个精选技能，每个都经过验证，覆盖 11 个职业

少而精，拿来就能用。

——

几个我自己常用的：

写周报 → 周报自动生成（丢进本周事项，直接出结构化周报）
写需求 → PRD 需求文档（用户故事 + 验收标准一次成型）
做调研 → 竞品调研（自动整理信息，输出对比分析表）
理思路 → 结构化头脑风暴（从模糊想法到可执行方案）
做数据 → 数据分析师（SQL + 图表 + 结论）

产品、运营、开发、设计、财务、HR、法务都有对应的 Skill。

——

不只是给 OpenClaw 用。

SkillHubs 上的 Skill 是标准 Markdown 格式，
Claude Code、Cursor、ChatGPT 也都能用。

下载 .md 文件，复制到你用的 AI 工具里就行。

用法：
网页下载 → 放进 .claude/skills/ 目录（Claude Code）
网页下载 → 粘贴为自定义指令（ChatGPT / Cursor）
CLI 安装 → npm install -g skillhubs，命令行直接搜索下载

——

免费、开源、中英文都有。
你也可以把自己好用的工作流做成 Skill 分享上去，还有积分奖励。

一个参考数据：根据 SkillsBench 研究，用精选 Skill 比普通提示词，任务完成率高 16.2 个百分点。核心原因就是质量筛选。
